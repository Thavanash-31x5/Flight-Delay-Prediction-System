✈️ AeroInsight – AI Flight Delay Prediction System
AeroInsight is an intelligent aviation analytics platform that predicts airline flight delays using machine learning and provides interactive dashboards for analyzing airline operational performance.
The system combines artificial intelligence, data analytics, and web application development to create a real-time aviation intelligence solution that helps understand flight delay patterns and airline efficiency.

🚀 Features
✨ AI-powered flight delay prediction
📊 Interactive aviation analytics dashboard
🔐 Secure user login and account creation system
📈 Visualization of airline delay trends
🌍 Airport activity insights and operational patterns
💾 Prediction history storage for analysis
🎨 Clean and modern user interface

🧠 Machine Learning Model
The prediction engine is powered by a Random Forest Regressor model. This algorithm analyzes airline operational parameters and predicts the expected delay time for flights.
The model learns patterns from historical airline data and estimates how different operational factors such as weather delays, carrier delays, cancellations, and diversions influence the final delay duration.
The output generated by the system is the predicted flight delay in minutes.

📊 Dashboard Analytics
The AeroInsight dashboard provides several aviation intelligence insights including model performance metrics, delay statistics, and visual trend analysis.
Users can view model accuracy, average flight delay, and the R² score of the machine learning model. The dashboard also displays monthly delay trends and visual insights that help understand airline operational behavior over time.
These analytics help identify patterns in airline performance and delay causes.

🖥️ Application Interface
The AeroInsight platform consists of three main modules.
🔐 Login System
Users can securely log in or create accounts to access the platform.
📊 Dashboard
Displays aviation analytics, delay trends, and model performance insights.
🔮 Prediction Engine
Allows users to input airline operational parameters and receive an AI-based prediction of expected flight delay.

⚙️ Technology Stack
🐍 Python for programming and backend logic
📊 Pandas and NumPy for data processing
🤖 Scikit-learn for machine learning model development
📈 Plotly for data visualization
🌐 Streamlit for building the interactive web application
🗄️ PostgreSQL with Supabase for storing user and prediction data

📊 Dataset
The dataset used in this project contains airline operational statistics such as flight counts, delay causes, cancellations, diversions, airline carriers, and airport information.
Due to repository size limitations, the dataset is provided as a compressed file. Users need to extract the dataset before running the application.

▶️ Running the Project
To run the project locally, users need to install the required dependencies and start the Streamlit application. Once launched, the application opens in the web browser where users can log in, explore analytics dashboards, and generate delay predictions.

🌐 Deployment
The AeroInsight platform can be deployed on cloud platforms that support Python web applications. Popular deployment options include Streamlit Cloud, Render, and Railway.
Deployment allows the project to run as a live web application accessible through a public URL.

📈 Model Performance
The Random Forest model demonstrates strong predictive capability with an accuracy of approximately 97 percent and a high R² score. This indicates that the model effectively captures patterns in airline operational data to estimate delay durations.
